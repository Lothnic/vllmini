# vLLMini

My own implementation of vLLM.


## Models supported

- [x] Llama 2/3 and their derivatives
- [x] Qwen 2/3 and their derivatives
- [ ] Mistral
- [ ] Mixtral
- [ ] Gemma
- [ ] Phi



## Installation

uv is recommended for dependency management.

```bash
git clone https://github.com/lothnic/vllmini.git
cd vllmini
uv sync
```
